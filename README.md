## 📋 Petunjuk Instalasi

### Panduan untuk Windows:
1. Unduh file `Sinlui CBT Browser Setup <versi>.exe`.
2. Klik dua kali pada file installer untuk memulai pemasangan.
3. Jika muncul jendela *Windows protected your PC (SmartScreen)*:
   - Klik **More info**
   - Klik **Run anyway**.
4. Selesaikan instalasi hingga ikon **Sinlui CBT Browser** muncul di Desktop.

### Panduan untuk macOS:
1. Unduh file `.dmg` yang sesuai dengan Mac Anda (Apple Silicon atau Intel).
2. Buka file `.dmg` yang telah diunduh.
3. Seret (*drag & drop*) ikon **Sinlui CBT Browser** ke dalam folder **Applications**.
4. Jika muncul peringatan saat pertama kali dibuka:
   - Buka **System Settings (Pengaturan Sistem)** > **Privacy & Security (Privasi & Keamanan)**.
   - Gulir ke bawah hingga bagian *Security*, lalu klik **Open Anyway (Tetap Buka)**.
